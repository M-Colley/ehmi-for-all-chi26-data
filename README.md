# eHMI for All (CHI 2026) Data and Analysis

This repository contains the data and analysis scripts for

**Colley, Kopp, Dey, Jansen, Rukzio (2026). _eHMI for All: Investigating the Effect of External Communication of Automated Vehicles on Pedestrians, Manual Drivers, and Cyclists in Virtual Reality._ CHI 2026.**  
DOI: https://doi.org/10.1145/3772318.3790585

## What is in this repo

1. **Anonymized study data**.
2. **R scripts** to reproduce the statistics, tables, and plots reported in the paper.
